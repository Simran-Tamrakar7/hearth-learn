Functional testing verifies that the application does what its requirements say it should do — given a specific input or action, does it produce the correct output or behavior, regardless of how the code is structured internally.

## Functional Business Logic Testing

Verify feature input/output constraints against product specifications using scripted and low-code tooling.

```
Functional Spec: Employee Leave Policy
- Valid range: 1-5 days -> Approved
- Invalid range: >5 days -> Rejected with validation message
```
